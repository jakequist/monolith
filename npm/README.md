# monosplice

This package is a downloader shim: installing it fetches the prebuilt [monosplice](https://github.com/jakequist/monosplice) binary (Rust) for your platform from GitHub Releases and puts it on your PATH.

Prefer the standalone installer, which needs no Node.js:

```sh
curl -fsSL https://github.com/jakequist/monosplice/releases/latest/download/install.sh | sh
```

Or build it from source with `cargo install monosplice`.
